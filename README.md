## Homepage changes
- FORM title moved into the left white strip as a vertical typographic element.
- FORM macro images now live in a smooth 3D rotating gallery wall.
- The active macro artwork always updates the larger matching full product image on the right.
- FORM internal wheel/drag progression is fractional and eased, so rotation feels continuous rather than card-by-card snapping.
- Lotus Bloom is now a magnetic floating gallery using lb1.3, lb1.4, lb1.2 and lb1.5.
- Lotus cards react to cursor/touch position and float through depth as the internal story advances.
- All visible “SCROLL · DRAG · SWIPE” instruction text has been removed.
- Wheel/trackpad and pointer/touch drag interactions remain active.
- FORM and Lotus still lock the page while their internal sequence is being explored, then release after reaching the end.
